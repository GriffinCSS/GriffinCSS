Расширенные поля форм второго бандла на одном экране — предмет браузерных тестов на трёх движках. Второй прогон идёт с отключённым griffinjs-fields.js: каждое поле обязано оставаться рабочим и так — это база без скрипта, условие приёмки.

Маска

Формат — строка токенов: 0 цифра, a буква, A буква в верхнем регистре, * буква или цифра, ? — необязательный хвост, \ — знак буквально. Без скрипта поле остаётся полем: pattern и inputmode — платформенные, и проверяет их платформа. Со скриптом data-gr-mask помогает вводить: литералы подставляются сами, каретка встаёт за введённым знаком, из формата берётся подсказка.

Телефон

Код страны в <select>, номер по маске выбранной страны. Состав — из разметки: value кода, data-gr-iso и data-gr-format на каждой позиции; пустой список заполняется из griffinjs-countries.js. Имя страны и флаг — у платформы, в языке страницы. База без скрипта — type="tel" и тот же список кодов в группе.

Дата и время

Разметка несёт нативное поле, и без скрипта форма работает как сегодня. На тач-устройстве виджет её не трогает — системный календарь остаётся; на указателе мыши тип подменяется на text, надевается маска по локали, ISO уходит в скрытый спутник с прежним именем, а границы min/max проверяет виджет через setCustomValidity. Панель — role="dialog", фокус остаётся в поле. Уход фокуса возвращает нативный тип. Поле времени виджет не трогает: выбор встроен в само поле.

Файловое поле

.gr-file — поле семьи: рамка, фокус и состояния те же, что у .gr-input, кнопка выбора — ::file-selector-button. Мультивыбор даёт multiple, и без скрипта поле показывает число выбранных само. Со скриптом data-gr-file добавляет список с размером в единицах локали и кнопкой «убрать» — один файл из выбранного без DataTransfer не убрать вовсе; append копит выбор вместо замены.

Ввод оценки

Пять радиокнопок в <fieldset> — база без скрипта. Со скриптом data-gr-rating пишет число выбранной в --gr-rating ряда .gr-rating, подпись выбранной — в его aria-label, а CSS слоя кладёт подписи поверх знаков. Наведение показывает оценку под указателем мыши; стрелки клавиатуры меняют выбор, как в любой группе радиокнопок.

Одноразовый код

Ряд ячеек maxlength="1" — база без скрипта: заполняются вручную, каждая уходит в форму своим значением. Со скриптом data-gr-otp набранный знак переводит фокус дальше, Backspace на пустой ячейке возвращает назад, код из буфера или из автозаполнения (autocomplete="one-time-code") раскладывается по ячейкам; полный код — событие griffin:complete.

Сводка ошибок формы

Без скрипта форму проверяет браузер и показывает пузырь у первого непройденного поля. Со скриптом data-gr-validate собирает все непройденные поля в сводку в начале формы: ссылки «подпись: сообщение платформы», фокус на первой, aria-invalid на полях; исправленное поле теряет пометку сразу, список обновляет следующая отправка.

Счётчик символов

Предел задаёт maxlength, и без скрипта он действует сам. Со скриптом data-gr-counter добавляет подпись с остатком после поля, связывает её с полем через aria-describedby и объявляет через aria-live; у порога подпись получает состояние near, на пределе — full.
