Colors

HSL-цветовая система: нейтральная шкала по золотому сечению, 6 акцентных цветов на цветовом круге (шаг 72°), семантические токены. Все цвета задаются через CSS-переменные — любой оттенок можно переопределить точечно.

Опциональный модуль scss/modules/_colors.scss _gradients.scss ~160 классов

Архитектура

Цветовая система состоит из трёх уровней: 

// 1. HSL-токены (низкоуровневые) — пользователь переопределяет hue/saturation/lightness
--gr-hsl-gray-100: 0, 0%, 89%;
--gr-hsl-primary:  220, 80%, 50%;

// 2. Семантические токены — используют HSL-переменные через hsl()
--gr-color-bg:      hsl(var(--gr-hsl-white));
--gr-color-text:    hsl(var(--gr-hsl-gray-900));
--gr-color-link:    hsl(var(--gr-hsl-primary));

// 3. Утилитарные классы — ссылаются на HSL-токены
.gr-bg-primary  { background-color: hsl(var(--gr-hsl-primary)); }
.gr-text-danger { color: hsl(var(--gr-hsl-danger)); }

Сила HSL: пользователь может изменить только hue акцентного цвета (например, --gr-hsl-primary: 260, 80%, 50% для фиолетового), и saturation с lightness останутся прежними. Или только lightness для тёмной темы: --gr-hsl-gray-100: 0, 0%, 15%.

Градиенты

Линейный градиент собирается из двух половин: класс направления рисует его, классы точек задают цвета. Своей палитры у группы нет — цвет берётся из тех же переменных --gr-hsl-*, что и .gr-bg-*, поэтому перенастроенная палитра перекрашивает градиенты вместе со всем остальным.

ГруппаКлассы
Направление.gr-gradient-to-r (вправо), -l, -t, -b, -br (вправо-вниз), -tr (вправо-вверх)
Начало.gr-from-primary / secondary / success / warning / danger / info / white / black
Середина.gr-via-* — те же восемь имён
Конец.gr-to-* — те же восемь имён

Незаданный конец прозрачен. Это не заглушка, а рабочий приём: .gr-gradient-to-t .gr-from-black — уже готовая подложка под подпись поверх фотографии, и второй класс цвета ей не нужен. Средняя точка необязательна и, пока не задана, не стоит ничего.

Направление плюс точки: два класса — уже градиент
.gr-gradient-to-br
.gr-from-primary .gr-to-info
.gr-gradient-to-r
.gr-from-danger .gr-via-warning .gr-to-success
.gr-bg-secondary
.gr-gradient-to-t .gr-from-black

Восемь имён вместо восемнадцати — плата за бюджет: три точки на всю палитру акцентов дали бы 54 класса и вывели griffincss-utils.css за потолок. Нужны -light и -dark-оттенки — либо переопределите $gr-gradient-colors в своей точке входа (см. справочник), либо задайте цвет прямо: --gr-from, --gr-via и --gr-to — обычные настраиваемые свойства. 

<div class="gr-gradient-to-r" style="--gr-from: hsl(var(--gr-hsl-primary-light)); --gr-to: hsl(var(--gr-hsl-primary-dark))">…</div>

Суффиксов брейкпоинта у градиентов нет и не будет. .gr-gradient-to-r-md не существует — как не существует .gr-scale-105-md. Декоративный фон не меняется от ширины окна, а адаптивные и контейнерные варианты умножили бы группу примерно вдевятеро и съели бы весь бюджет утилит.

Градиент — это background-image, а не background-color. Поэтому он ложится поверх .gr-bg-* и не конфликтует с ним: цвет фона остаётся видимым там, где градиент прозрачен, — на этом и держится третий пример выше. Текст на градиенте нужно проверять на контраст в обеих его точках: белые буквы, читаемые на тёмном конце, на светлом пропадают.

Кастомизация

Все цвета строятся на HSL-переменных. Для тёмной темы достаточно переопределить lightness: 

:root {
  /* Инвертируем серую шкалу */
  --gr-hsl-white:    0, 0%, 8%;
  --gr-hsl-gray-50:  0, 0%, 13%;
  --gr-hsl-gray-100: 0, 0%, 21%;
  --gr-hsl-gray-200: 0, 0%, 29%;
  --gr-hsl-gray-300: 0, 0%, 38%;
  --gr-hsl-gray-400: 0, 0%, 50%;
  --gr-hsl-gray-500: 0, 0%, 67%;
  --gr-hsl-gray-600: 0, 0%, 82%;
  --gr-hsl-gray-700: 0, 0%, 89%;
  --gr-hsl-gray-800: 0, 0%, 96%;
  --gr-hsl-gray-900: 0, 0%, 100%;
  --gr-hsl-black:    0, 0%, 100%;

  /* Делаем primary фиолетовым */
  --gr-hsl-primary:       260, 80%, 50%;
  --gr-hsl-primary-light: 260, 80%, 65%;
  --gr-hsl-primary-dark:  260, 80%, 35%;
}

Точечная кастомизация. Не нужно переопределять все переменные. Измените только --gr-hsl-primary — и все классы .gr-bg-primary, .gr-text-primary, .gr-border-primary подхватят новый цвет автоматически.

Своя палитра на компилтайме

Всё выше — кастомизация без пересборки: имена классов остаются, меняются значения. Собирающий библиотеку из исходников может пойти дальше и заменить сам состав: карты $gr-grays и $gr-accents помечены !default, поэтому вместо восемнадцати акцентов в CSS выйдут ровно те, что нужны проекту.

Половин две, и обе обязательны. Карта задаёт имена классов и то, из какой переменной берётся цвет. Сами --gr-hsl-* приходят из темы ядра. Переопределив карту и не заведя переменных, вы получите .gr-bg-brand, ссылающийся в пустоту: hsl(var(--gr-hsl-brand)) не из чего вычислить.

Полный пример с обеими половинами, замером и разбором частой ошибки — Справочник утилит, «Своя палитра и своя шкала».

SCSS-реализация

// _colors.scss — все классы генерируются циклами @each
// !default: обе карты переопределяются при сборке из исходников

$gr-grays: (
  "white": var(--gr-hsl-white), gray-50: var(--gr-hsl-gray-50),
  ... gray-900, "black"
) !default;

$gr-accents: (
  primary: var(--gr-hsl-primary), primary-light: ..., primary-dark: ...,
  secondary, success, warning, danger, info (+ light/dark каждого)
) !default;

// Фоновые утилиты
@each $name, $hsl in $gr-grays {
  .gr-bg-#{$name} { background-color: hsl(#{$hsl}); }
}
@each $name, $hsl in $gr-accents {
  .gr-bg-#{$name} { background-color: hsl(#{$hsl}); }
}

// Аналогично для gr-text-* и gr-border-*

Советы

Семантические токены для сайта, утилиты для компонентов. --gr-color-bg и --gr-color-text — для базовых стилей страницы. .gr-bg-primary и .gr-text-danger — для отдельных элементов и состояний.

Не смешивайте с HEX/RGB. Если вы используете HSL-систему Griffincss, задавайте все цвета через --gr-hsl-* переменные. Смешение HSL и HEX приводит к дублированию цветов и усложняет кастомизацию.

Light/dark варианты — автоматические. -light = L+15%, -dark = L−15%. Не переопределяйте их hue или saturation — только lightness, если нужно. Для кардинальной смены оттенка меняйте базовый токен (без -light/-dark).

Примеры использования

Цвет в интерфейсе — почти всегда пара или тройка согласованных утилит: бледный фон со своим тёмным текстом, точка со своей подписью, насыщенная секция со своей инверсией. Рецепты ниже показывают эти связки вместе с отступами, бордерами и компонентами ui — и то, как токены сами перекрашивают собранное при смене темы.

Декоративный фон секции

Первый экран или блок «Призыв к действию»: вместо плоской заливки — переход между двумя соседями по цветовому кругу. Диагональ .gr-gradient-to-br читается живее горизонтали, а пара primary → info держит один температурный ряд. Текст поверх берёт .gr-text-white, вторичный — его же с .gr-opacity-75; кнопка инвертируется в белую с акцентным текстом, чтобы не спорить с фоном.

Подпись поверх фотографии собирается тем же механизмом, но без второго цвета: .gr-gradient-to-t .gr-from-black — чёрный снизу, прозрачный сверху. Слой лежит поверх снимка и под текстом, и буквы читаются на любом кадре, не затемняя картинку целиком. 

<section class="gr-radius-3 gr-p-8 gr-text-center gr-gradient-to-br gr-from-primary gr-to-info gr-text-white">
  <h2 class="gr-mt-0 gr-mb-2">Попробуйте на своём проекте</h2>
  <p class="gr-opacity-75 gr-mb-4">Установка — одна строка</p>
  <button class="gr-btn gr-bg-white gr-text-primary">Начать</button>
</section>

Статусные пары: бледный фон + тёмный текст

Правило одного оттенка: подложка — -light-ступень цвета, текст на ней — -dark-ступень того же цвета. Контраст обеспечен разницей светлоты в 30%, а оттенок остаётся один, поэтому блок выглядит цельным. Так собирается уведомление любой семантики — success, danger, warning, info. Для повседневной работы то же самое в готовом виде умеет .gr-alert-* из ui — здесь показана механика, на которой он стоит.

Статусные точки: цвет + подпись

Состояние в таблице или списке маркирует цветная точка .gr-dot-* из ui рядом с текстом — флекс с мелким зазором выравнивает их по центру строки. На аватаре та же точка становится индикатором «онлайн» через позиционирование: .gr-absolute .gr-bottom-0 .gr-end-0 в нижнем углу у конца строки родителя (в LTR — правом) с .gr-relative — цвет здесь работает вместе с Position.

  <span class="gr-dot gr-dot-success"></span> Активен
</span>

  <span class="gr-avatar">АК</span>

Акцентная CTA-полоса

Секция на насыщенном брендовом фоне: .gr-bg-primary + .gr-text-white на контейнере — цвет текста наследуется всем содержимым. Второстепенная строка приглушается не серым (на синем он грязнит), а прозрачностью: .gr-opacity-75. Кнопка инвертируется той же парой наоборот — .gr-bg-white .gr-text-primary.

Тёмный островок: инверсия темой, а не классами

Когда инвертировать нужно не пару цветов, а всё сразу — карточку с текстом, бордерами и кнопками, — перекрашивание вручную не масштабируется. Правильный инструмент — атрибут data-gr-theme="dark" на секции: все семантические токены внутри переключаются на тёмные значения, и любой элемент на токенах перекрашивается сам. Это та же механика, что у тёмной темы всей страницы, — подробности на странице Темы. 

<div class="gr-card gr-p-6" data-gr-theme="dark">
  <h3>Тёмный островок</h3>
  <p>Фон, текст и бордеры взяли тёмные значения токенов — классы не менялись.</p>
  <button class="gr-btn gr-btn-primary">Кнопка как кнопка</button>
</div>
Островок data-gr-theme="dark": перекраска приходит из токенов

Выбранный пункт меню: тонировка + маркер

Активный пункт сайдбара или фильтра собирается из трёх слоёв: нейтральная подложка .gr-bg-gray-100, цветной текст .gr-text-primary .gr-font-semibold и цветной маркер у начала строки (в LTR — слева) — .gr-border-s-4 .gr-border-primary. Ховер-вариантов у утилит нет намеренно: наведение — дело компонентов (.gr-nav) или одной строки своего CSS, а утилиты размечают состояния, которыми управляет разметка, — как aria-current здесь. 

<nav class="gr-flex gr-flex-col gr-gap-sm">
  <a class="gr-p-2 gr-radius-2 gr-text-ink-secondary gr-no-underline" href="#">Обзор</a>
  <a class="gr-p-2 gr-radius-2 gr-bg-gray-100 gr-text-primary gr-font-semibold
            gr-border-s-4 gr-border-primary gr-no-underline" aria-current="page" href="#">Отчёты</a>
  <a class="gr-p-2 gr-radius-2 gr-text-ink-secondary gr-no-underline" href="#">Настройки</a>
</nav>
