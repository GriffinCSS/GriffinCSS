Colors

HSL-цветовая система: нейтральная шкала по золотому сечению, 6 акцентных цветов на цветовом круге (шаг 72°), семантические токены. Все цвета задаются через CSS-переменные — любой оттенок можно переопределить точечно.

Опциональный модуль scss/modules/_colors.scss ~160 классов

Архитектура

Цветовая система состоит из трёх уровней: 

// 1. HSL-токены (низкоуровневые) — пользователь переопределяет hue/saturation/lightness
--gr-hsl-gray-100: 0, 0%, 89%;
--gr-hsl-primary:  220, 80%, 50%;

// 2. Семантические токены — используют HSL-переменные через hsl()
--gr-color-bg:      hsl(var(--gr-hsl-white));
--gr-color-text:    hsl(var(--gr-hsl-gray-900));
--gr-color-link:    hsl(var(--gr-hsl-primary));

// 3. Утилитарные классы — ссылаются на HSL-токены
.gr-bg-primary  { background-color: hsl(var(--gr-hsl-primary)); }
.gr-text-danger { color: hsl(var(--gr-hsl-danger)); }

Сила HSL: пользователь может изменить только hue акцентного цвета (например, --gr-hsl-primary: 260, 80%, 50% для фиолетового), и saturation с lightness останутся прежними. Или только lightness для тёмной темы: --gr-hsl-gray-100: 0, 0%, 15%.

  color: var(--gr-color-link);
}

  color: var(--gr-color-link-hover);
}

Кастомизация

Все цвета строятся на HSL-переменных. Для тёмной темы достаточно переопределить lightness: 

:root {
  /* Инвертируем серую шкалу */
  --gr-hsl-white:    0, 0%, 8%;
  --gr-hsl-gray-50:  0, 0%, 13%;
  --gr-hsl-gray-100: 0, 0%, 21%;
  --gr-hsl-gray-200: 0, 0%, 29%;
  --gr-hsl-gray-300: 0, 0%, 38%;
  --gr-hsl-gray-400: 0, 0%, 50%;
  --gr-hsl-gray-500: 0, 0%, 67%;
  --gr-hsl-gray-600: 0, 0%, 82%;
  --gr-hsl-gray-700: 0, 0%, 89%;
  --gr-hsl-gray-800: 0, 0%, 96%;
  --gr-hsl-gray-900: 0, 0%, 100%;
  --gr-hsl-black:    0, 0%, 100%;

  /* Делаем primary фиолетовым */
  --gr-hsl-primary:       260, 80%, 50%;
  --gr-hsl-primary-light: 260, 80%, 65%;
  --gr-hsl-primary-dark:  260, 80%, 35%;
}

Точечная кастомизация. Не нужно переопределять все переменные. Измените только --gr-hsl-primary — и все классы .gr-bg-primary, .gr-text-primary, .gr-border-primary подхватят новый цвет автоматически.

Практический пример: alert-компонент

<!-- Успех -->
<div class="gr-bg-success-light gr-p-4 gr-radius-2">
  <p class="gr-text-success-dark gr-font-semibold">Операция выполнена успешно</p>
  <p class="gr-text-success-dark">Данные сохранены.</p>
</div>

<!-- Ошибка -->
<div class="gr-bg-danger-light gr-p-4 gr-radius-2">
  <p class="gr-text-danger-dark gr-font-semibold">Ошибка</p>
  <p class="gr-text-danger-dark">Не удалось сохранить данные.</p>
</div>

<!-- Предупреждение -->
<div class="gr-bg-warning-light gr-border-2 gr-border-warning gr-p-4 gr-radius-2">
  <p class="gr-font-semibold">Внимание</p>
  <p>Срок действия подписки истекает через 3 дня.</p>
</div>
Результат

Операция выполнена успешно

Данные сохранены.

Ошибка

Не удалось сохранить данные. Проверьте подключение.

Внимание

Срок действия подписки истекает через 3 дня.

SCSS-реализация

// _colors.scss — все классы генерируются циклами @each

$gr-grays: (
  "white": var(--gr-hsl-white), gray-50: var(--gr-hsl-gray-50),
  ... gray-900, "black"
);

$gr-accents: (
  primary: var(--gr-hsl-primary), primary-light: ..., primary-dark: ...,
  secondary, success, warning, danger, info (+ light/dark каждого)
);

// Фоновые утилиты
@each $name, $hsl in $gr-grays {
  .gr-bg-#{$name} { background-color: hsl(#{$hsl}); }
}
@each $name, $hsl in $gr-accents {
  .gr-bg-#{$name} { background-color: hsl(#{$hsl}); }
}

// Аналогично для gr-text-* и gr-border-*

Советы

Семантические токены для сайта, утилиты для компонентов. --gr-color-bg и --gr-color-text — для базовых стилей страницы. .gr-bg-primary и .gr-text-danger — для отдельных элементов и состояний.

Не смешивайте с HEX/RGB. Если вы используете HSL-систему Griffincss, задавайте все цвета через --gr-hsl-* переменные. Смешение HSL и HEX приводит к дублированию цветов и усложняет кастомизацию.

Light/dark варианты — автоматические. -light = L+15%, -dark = L−15%. Не переопределяйте их hue или saturation — только lightness, если нужно. Для кардинальной смены оттенка меняйте базовый токен (без -light/-dark).
