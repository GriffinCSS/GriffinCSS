Настройка

Геометрия теней отделена от цвета. Цвет задаётся одной переменной --gr-shadow-color в формате HSL-компонент — перекрасить все семь теней разом можно, не трогая ни одну из них: 

:root {
  /* холодная синеватая тень вместо нейтральной чёрной */
  --gr-shadow-color: 220, 40%, 20%;
}

Отдельная тень переопределяется так же, обычной переменной:

:root {
  --gr-shadow-md: 0 2px 8px hsl(var(--gr-shadow-color), 14%);
}

Токены --gr-shadow-* объявлены в _tokens.scss ядра, поэтому приезжают и с griffincss-core.css, и с griffincss-utils.css: блок :root в обеих сборках обязан совпадать — это отдельно проверяется при сборке.
