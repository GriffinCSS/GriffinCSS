Настройка

Геометрия теней отделена от цвета. Цвет задаётся одной переменной --gr-shadow-color в формате HSL-компонент — перекрасить все семь теней разом можно, не трогая ни одну из них: 

:root {
  /* холодная синеватая тень вместо нейтральной чёрной */
  --gr-shadow-color: 220, 40%, 20%;
}

Отдельная тень переопределяется так же, обычной переменной:

:root {
  --gr-shadow-md: 0 2px 8px hsl(var(--gr-shadow-color), 14%);
}

Токены --gr-shadow-* объявлены в _tokens.scss ядра, поэтому приезжают и с griffincss-core.css, и с griffincss-utils.css: блок :root в обеих сборках обязан совпадать — это отдельно проверяется при сборке.

Примеры использования

Тень — язык глубины: чем «выше» элемент над страницей, тем крупнее его тень. Рецепты ниже показывают, как ступени шкалы распределяются по слоям интерфейса и как тень работает в паре с бордерами, скруглениями и позиционированием.

Слои интерфейса: одна шкала на все этажи

Правило простое: покоящееся — sm, всплывающее — lg, модальное — 2xl. Карточка списка лежит почти на странице, выпадающее меню висит над ней, диалог — над всем окном. Когда каждая ступень закреплена за своим этажом, глубина читается без легенды — и меняется одним токеном --gr-shadow-strength, а не правкой всех теней по одной. 

<div class="gr-card gr-shadow-sm">Карточка списка</div>
<ul class="gr-radius-2 gr-shadow-lg">Выпадающее меню</ul>
<dialog class="gr-radius-4 gr-shadow-2xl">Диалог</dialog>
Покой — sm, всплытие — lg, модальность — 2xl

Тень-«блюдце» под скриншотом

Маркетинговый приём: большой скриншот продукта в hero отрывается от страницы крупной мягкой тенью. Достаточно пары .gr-radius-4 .gr-shadow-2xl на картинке — и блок выглядит «поднятым», без единой строки своего CSS. Центрирует его знакомая пара .gr-w-fit .gr-mx-auto. 

<div class="gr-w-fit gr-mx-auto">
  <img class="gr-radius-4 gr-shadow-2xl" src="screenshot.png" alt="Экран приложения">
</div>
Скриншот поднимает .gr-shadow-2xl

Вдавленные поверхности

Обратная сторона глубины: то, что «утоплено» в страницу. Трек прогресс-бара, поле поиска на цветной панели, колодец со статистикой — их делает пара «чуть темнее фон + тень внутрь»: .gr-bg-sunken .gr-shadow-inner. Выпуклое и вдавленное на одном экране усиливают друг друга — сравните колодец с карточкой рядом. 

<div class="gr-bg-sunken gr-shadow-inner gr-radius-2 gr-p-4">
  Вдавленный колодец
</div>
Вниз — .gr-shadow-inner, вверх — .gr-shadow-md

Вдавленный колодец

.gr-bg-sunken + .gr-shadow-inner

Выпуклая карточка

.gr-bg-surface + .gr-shadow-md

Подъём по ховеру — честно про границы модуля

Классический «hover lift» — тень на ступень выше при наведении — ховер-вариантами утилит не собирается: их в библиотеке нет намеренно. У готового .gr-card-interactive подъём есть из коробки; для своего элемента это три строки CSS на токенах — геометрия и цвет тени останутся согласованными с темой: 

.promo-card { transition: box-shadow 0.15s ease; }
.promo-card:hover { box-shadow: var(--gr-shadow-lg); }
Готовый подъём: .gr-card .gr-card-interactive (наведите курсор)
