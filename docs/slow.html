Slow Load Test

Страница имитирует медленную загрузку JS. data-auto="false" на теге script отключает автоинициализацию. Через 3 секунды Griffincss.init() вызывается вручную — гриды раскладываются.

С v0.7.0 FOUC-защиты в статическом CSS нет: правило opacity: 0 ставит сам рантайм при загрузке. Если скрипт заблокирован или не выполнился, правила нет — и контент остаётся читаемым, пусть и без сетки. При data-auto="false" защита появляется только вместе с вызовом init(), поэтому до него блоки видны.

Плавного проявления здесь не будет, и это не сбой. Правило opacity: 0 и класс .gr-ready появляются внутри одного вызова init(), то есть в одном кадре — состояние «прозрачно» браузер ни разу не отрисовывает, и переходу не от чего стартовать. Плавное появление видно там, где защита стоит с загрузки скрипта, а раскладка приходит секундами позже: stream-off.html.

Этот блок с классом .gr-flex виден всегда — он не зависит от data-gr-layout. CSS-утилиты (flex, spacing, visibility) работают без JS.
