Reset & Переменные

Минимальный CSS reset и система CSS custom properties — фундамент, на котором строится вся библиотека.

CSS Reset

Griffincss включает минимальный, но тщательно продуманный сброс стилей. Ничего лишнего — только то, что действительно нужно для современной вёрстки.

Что делает reset

ПравилоНазначение
box-sizing: border-boxУ всех элементов и псевдоэлементов. Размеры включают padding и border.
html { scroll-behavior: smooth }Плавная прокрутка при якорных ссылках — только внутри @media (prefers-reduced-motion: no-preference): безусловная плавная прокрутка вызывает укачивание у части пользователей.
html { -webkit-text-size-adjust: 100% }Отключает автоувеличение шрифта при повороте экрана в iOS Safari.
body { margin: 0; padding: 0; min-height: 100vh }Убирает стандартные отступы, растягивает на весь viewport.
body { line-height: 1.5 }Читаемый интерлиньяж по умолчанию. Размер и семейство шрифта не задаются.
Сглаживание шрифта-webkit-font-smoothing: antialiased, -moz-osx-font-smoothing: grayscale
Обнуление margin у заголовков, параграфовh1–h6, p, figure, blockquote, dl, dd
Медиа-элементы как блокиimg, picture, video, canvas, svg { display: block; max-width: 100% }
Наследование шрифта и цвета у формinput, button, textarea, select { font: inherit; color: inherit }
Курсор у кнопокbutton { cursor: pointer }
Сброс списковul[role="list"], ol[role="list"] { list-style: none; padding: 0; margin: 0 } — маркеры снимаются только со списков, размеченных как список явно. Обычный <ul> в тексте сохраняет и маркеры, и отступ, а role="list" оставляет элементу роль списка в скринридере при снятом оформлении.
Сброс таблицtable { border-collapse: collapse; border-spacing: 0 }
a { color: inherit; text-decoration: none }Ссылки наследуют цвет, без подчёркивания.
[hidden]:not([hidden="until-found"]) { display: none }Атрибут hidden гарантированно скрывает элемент. С 0.26.0 правило лежит не в слое ресета, а в последнем слое библиотеки griffincss.hidden и едет из каждой сборки: из нижнего слоя оно проигрывало любому display компонента, и <nav class="gr-nav" hidden> оставался на экране. hidden="until-found" не трогается — браузер держит такой элемент для поиска по странице.

Осознанный минимализм: reset не сбрасывает шрифты и размеры текста — вы сами выбираете типографику для проекта. Он убирает только browser inconsistencies, которые мешают вёрстке.

CSS Custom Properties

Все ключевые значения библиотеки вынесены в CSS-переменные на :root. Это позволяет переопределять их в рантайме без пересборки SCSS — просто задайте новое значение в своём CSS или через JavaScript.

Полный список переменных

Все токены объявлены в одном месте — packages/core/scss/_tokens.scss пакета griffincss-core, а в собранных файлах лежат в одном слое griffincss.tokens: ваш подслой после него переопределяет любой токен при любой специфичности. Пакет griffincss-utils подключает этот же файл, поэтому блок :root в обеих сборках одинаковый и любую из них можно подключать отдельно.

Переопределение переменных

Чтобы изменить значения под свой проект, переопределите нужные переменные в вашем CSS:

:root {
  --gr-gap: 1.25rem;
  --gr-max-width: 1200px;
  --gr-radius: 0.75rem;
  --gr-bp-md: 800px;
}

Или через JavaScript в рантайме:

document.documentElement.style.setProperty('--gr-gap', '1.25rem');
document.documentElement.style.setProperty('--gr-bp-md', '800px');

JS-рантайм и брейкпоинты: griffincss.js читает значения --gr-bp-* из computed styles при инициализации. Поэтому переопределять брейкпоинты нужно до загрузки JS-скрипта или до вызова Griffincss.init() (если автоинициализация отключена).

Категории переменных

Spacing

--gr-gap, --gr-gap-sm, --gr-gap-lg — управляют отступами в grid- и flex-контейнерах и в раскладках. Значения по умолчанию подрастают с брейкпоинта md, поэтому классы .gr-gap-* адаптивны сами по себе. Переопределение в :root отключает этот шаг — значение станет фиксированным.

Layout

--gr-max-width — максимальная ширина для .gr-container. Ограничивает контент на широких экранах.

Visual

--gr-radius, --gr-transition — базовые визуальные токены для использования в собственных компонентах.

Breakpoints

--gr-bp-sm … --gr-bp-xl — справочные значения, читаемые JS-рантаймом для адаптивных раскладок. Собираются из единственной карты $gr-breakpoints в scss/_breakpoints.scss.

Печать

Ресет несёт блок @media print. Он приезжает вместе с ресетом и только с ним: griffincss-reset.css — отдельная точка входа, не подключили — на печать ничего из этого не поедет.

ПравилоЗачем
body { background: #fff; color: #000 }Тема и бумага — разные среды. Фоны браузер по умолчанию не печатает, и светлый текст тёмной темы исчез бы на белом листе. Значения намеренно буквальные: смысл в том, чтобы выйти из темы, а не сменить её.
details::details-content { content-visibility: visible }Свёрнутый <details> на бумаге — потерянный текст: раскрыть его читатель уже не сможет. Селектор понимают не все браузеры — там правило отбрасывается как невалидное, и раздел печатается свёрнутым, как раньше.
h1–h6 { break-after: avoid }Заголовок не остаётся один в конце страницы.
blockquote, figure, img, pre, table { break-inside: avoid }Таблица, картинка и блок кода не разрываются посередине.
p { orphans: 3; widows: 3 }Одна строка абзаца, оторванная от остальных, читается как обрывок.

Тени гасятся не здесь, а в теме — и потому во всех сборках. Ресет живёт в самом младшем слое griffincss.reset, и правило box-shadow: none оттуда проиграло бы и компоненту, и утилите .gr-shadow-*. Поэтому на печати обнуляется множитель --gr-shadow-strength: семь готовых теней собраны из него, и ноль означает нулевую непрозрачность у каждой — в ядре, в компонентах и в утилитах разом, независимо от слоя и от того, подключён ли ресет.

Там же, в griffincss-utils.css, на печати останавливаются .gr-animate-spin и классы переходов: вращающийся индикатор печатается замершим в случайном положении.

FOUC-защита

Grid-контейнеры с data-gr-layout скрываются через opacity: 0 до обработки JS-рантаймом. После генерации CSS-правил JS добавляет класс .gr-ready — контейнер плавно проявляется. 

/* Внедряется рантаймом в <style id="griffincss-dynamic">.
   В собранном griffincss-core.css этого правила нет. */
[data-gr-layout]:not(.gr-ready),
[data-gr-layout-sm]:not(.gr-ready),
[data-gr-layout-md]:not(.gr-ready),
[data-gr-layout-lg]:not(.gr-ready),
[data-gr-layout-xl]:not(.gr-ready),
[data-gr-layout-csm]:not(.gr-ready),
[data-gr-layout-cmd]:not(.gr-ready),
[data-gr-layout-clg]:not(.gr-ready),
[data-gr-layout-cxl]:not(.gr-ready) {
  opacity: 0;
}

[data-gr-layout].gr-ready,
[data-gr-layout-sm].gr-ready,
… /* и так далее по всем девяти атрибутам */ {
  opacity: 1;
  transition: opacity 0.3s ease;
}

Почему opacity, а не display:none? opacity: 0 сохраняет геометрию элемента — он занимает место в потоке. Это предотвращает Cumulative Layout Shift (CLS) при загрузке страницы. Контейнер невидим, но его размеры уже учтены браузером.

Правила нет в статическом CSS — и это принципиально. Его первым же действием внедряет griffincss.js. Если скрипт заблокирован, не загрузился или упал, правило не появляется вовсе — контент остаётся видимым, пусть и без сетки. Ценой становится краткий кадр без раскладки, а не пустая страница. Контейнер открывается (получает .gr-ready) даже когда раскладка невалидна или значение атрибута пустое.
