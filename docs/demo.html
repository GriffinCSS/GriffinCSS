Griffincss Demo

Модульная SCSS-библиотека на основе CSS Grid и Flexbox. Grid-раскладки генерируются автоматически из data-gr-layout атрибутов.

1. Grid через data-gr-layout (буквы)

data-gr-layout="a3b4-c2d5" — Ряд 1: область a × 3 + область b × 4. Ряд 2: область c × 2 + область d × 5. JS-рантайм парсит атрибут и генерирует CSS на лету.

A (3 колонки)
B (4 колонки)
C (2 колонки)
D (5 колонок)

1b. Вложенный grid — независимость от вложенности

Родительский блок data-gr-layout="a3b4-c2d5". Внутри области b — такая же раскладка a3b4-c2d5. Внутри области d — другая раскладка e1f3. Имена grid-area (gr-area-a) не конфликтуют — каждый grid-контейнер изолирует свои области. JS-рантайм генерирует CSS-правила однократно: набор раскладок хешируется в класс .gr-l-<хеш>, и он вместе с .gr-area-a объявлен по одному разу, несмотря на повторное использование.

9. Адаптивный data-gr-layout по брейкпоинтам

Один контейнер — разные раскладки на разных разрешениях. data-gr-layout="a1b1" (базовая: 2 колонки), data-gr-layout-md="a3b4-c2d5" (≥768px: 7 колонок), data-gr-layout-lg="hdr4-main4-side2_2-ftr4" (≥1024px: страничная). Без классов gr-hidden-* — JS-рантайм автоматически генерирует CSS-правила, скрывающие gr-area-* элементы, чьё имя отсутствует в grid-template-areas текущего брейкпоинта. * Все 8 дочерних элементов присутствуют в HTML без классов скрытия. JS-рантайм для каждой раскладки генерирует правило .gr-l-<хеш> > [class*="gr-area-"]:not(.gr-area-X):not(.gr-area-Y) { display: none }, автоматически скрывая элементы, чьи grid-area не входят в текущий шаблон.

10. Авто-присвоение grid-area + блок на нескольких строках

Если дочерним элементам НЕ указан класс gr-area-*, JS-рантайм присваивает их автоматически в порядке документа, беря имена из базового data-gr-layout. Имена, занимающие несколько строк (как hero здесь), пропускаются при повторном появлении — подразумевается один и тот же блок. Важно: область на нескольких строках должна занимать одинаковые колонки (образовывать прямоугольник) — это требование CSS Grid.

11. Каскадный border-radius

.gr-radius — контейнер с каскадным border-radius. Прямые потомки автоматически получают радиус = max(0, parent-r − gap). --gr-r задаёт радиус контейнера. Зазор --gr-p задаётся переменной, из неё же выводится padding контейнера — JS для каскада не нужен.

Каждый вложенный .gr-radius явно задаёт --gr-r. Каскад работает на прямых потомках. --gr-p задаёт зазор, из него выводится padding.

12. Классы предопределённых радиусов

.gr-radius-{0..16} — радиус от 0 до 4rem с шагом 0.25rem. .gr-radius-full — полное скругление (9999px). Совместимы с .gr-radius для каскада. Адаптивный радиус задаётся переменной --gr-r в своём медиа-запросе.

.gr-radius-6 (1.5rem)
.gr-radius-8 (2rem)
